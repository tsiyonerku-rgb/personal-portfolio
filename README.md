# My Personal Profile Website
This is my first personal profile website. I created this project while learning HTML and basic web development.

## About the Project
This website contains information about me, my education, my skills, and my contact information.
It also has a navigation menu to help users move between different sections of the website.

## Features
* Personal profile information
* Navigation menu
* Skills section
* Contact section
* Contact form
* Email and phone number
* Footer
## Technologies Used
* HTML
## How to View the Project
1. Open the project folder.
2. Open the `portfolio.html` file.
3. View the website in your web browser.
